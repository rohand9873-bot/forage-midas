JPMorgan Chase Software Engineering Virtual Experience
This repository contains my work for the JPMorgan Chase & Co. Software Engineering Virtual Experience on Forage

📌 Project Description
In this task, I worked on a Spring Boot application that processes financial transaction data.
The main responsibilities included:

🔄 Consuming Kafka transaction streams
🎯 Applying incentive logic to transactions
💾 Persisting processed data in an H2 in-memory database
✅ Validating results using SQL queries and integration testing


⚡ Key Changes I Made
📝 Implemented Kafka consumer logic in the Spring Boot service
🎯 Added business incentive logic to adjust transaction values
💾 Configured H2 database and saved processed transactions
🔍 Tested and validated data through queries & integration tests

Language: ☕ Java
Framework: 🌱 Spring Boot
Tools: 📡 Kafka, 🗄️ H2 Database, 🛠️ Maven
